# مساحة حرة

تطبيق عربي بسيط يعمل محليًا من المتصفح، بدون تسجيل دخول أو قاعدة بيانات خارجية.

## التخزين والنسخ الاحتياطي

- بيانات اللوحة والكراسة تُحفظ في `localStorage` على هذا الجهاز والمتصفح.
- استخدم زر **إنشاء نسخة احتياطية** لإنشاء ملف JSON يجمع بيانات اللوحة والكراسة معًا.
- استخدم **استيراد** لاستعادة البيانات أو دمجها.
- لا تنتقل البيانات تلقائيًا بين الأجهزة.

## التشغيل المحلي

شغّل خادمًا محليًا من مجلد المشروع:

```powershell
npx serve .
```

ثم افتح الرابط الذي يظهره الخادم.
